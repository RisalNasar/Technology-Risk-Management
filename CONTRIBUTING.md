# Contributing to Technology Risk Management

Contributions are welcome. These guidelines help keep the repo consistent and easy to maintain.

## How to contribute

1. **Fork the repository** and create a branch from `master` (e.g. `fix/typo-readme` or `docs/add-backup-section`).
2. **Edit content** in Markdown (`.md`) or other existing formats. Keep the same structure and tone as existing docs.
3. **Use descriptive commit messages** (e.g. "Fix typo in README" or "Add section on key rotation") instead of generic "updated".
4. **Open a Pull Request** against `master` with a short description of your changes.

## Content guidelines

- Keep language neutral and professional; avoid company-specific or confidential examples.
- Prefer links to authoritative or current sources where relevant.
- Fix typos and broken links when you see them.
